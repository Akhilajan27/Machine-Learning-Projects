# 📌 Project Overview

Recruitment is one of the most critical business processes in every organization. Screening a large number of job applications manually can be time-consuming, inefficient, and susceptible to human bias.

This project leverages **Machine Learning** to predict hiring decisions using candidate information such as education, experience, interview performance, skills, personality assessment, and recruitment strategy.

The application is built using **Python**, **Scikit-learn**, and **Streamlit**, providing an interactive dashboard that helps HR professionals make faster, smarter, and data-driven hiring decisions.

# 🤖 Machine Learning Models

The following Machine Learning classification algorithms were trained and evaluated:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gradient Boosting Classifier

Hyperparameter tuning was performed using **GridSearchCV** to identify the optimal model.
